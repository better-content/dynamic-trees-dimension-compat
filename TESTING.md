# Verification

Use Java 17 and the checkout wrapper. `verifyFast` retains the seven existing resource contracts and adds an owned-ID/primitive-resource mapping contract. `verifyFull stageRuntimeJar --max-workers=2` additionally runs one nonshipping Forge GameTest in a new `build/gametest/<UUID>` directory, then validates its current-token execution receipt and native log.

The native fixture pins the pack's Immersive Weathering file 6116941, Moonlight file 8261419, and Patchouli file 7731017, plus the existing Dynamic Trees 1.4.10 and Undergarden file 5182632. Patchouli exercises the real supported branch of DT's conditional guide recipe; without it the pinned upstream recipe falls through to a malformed empty alternative. The first strict-failing attempt is retained rather than waiving this error. These optional integration dependencies are fixture-only; neither fixture classes/resources nor a mandatory IW dependency ship in the production JAR. Its own pack metadata and binary structure are packaged on the separate fixture source set.

The contract compares six **effective generated** loot resources (three owned DT types and three unmodified ordinary Undergarden controls) with the real pinned IW oak template. Only the pile identity and its primitive leaf item may differ: every count, condition and function stays native. It resolves item entries against the real registry, verifies dynamic leaves are block-only identities, and executes 54 actual loot rolls covering layers 0–8 with shears and Silk Touch. This checks that the strict optional generator mixin activates and fixes the higher-priority dynamic pack, rather than relying on a losing static override. Missing/empty parsed loot tables fail. Current-run native ERROR/FATAL records fail.

This focused Forge 47.4.13 source fixture is not exact-pack Forge 47.4.22 Smoke/Soak acceptance, client rendering, unrelated IW features, or a complete tool/explosion matrix. The unchanged native template comparison protects the unexercised functions/conditions structurally; only the stated tool/layer cases execute natively. With IW absent, `@Pseudo` makes the optional target inert; with the pinned target present the injector requires exactly a successful match (`require=1`, no error waiver).
